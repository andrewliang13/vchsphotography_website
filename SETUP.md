# VCHS Photography Club — Setup Guide

Static site for Cloudflare Pages. Content lives in `data/*.json`; portfolio pages are generated by `scripts/build_site.py`.

## Local preview

```bash
python3 scripts/build_site.py
python3 -m http.server 8765
```

Open http://127.0.0.1:8765/

## Hosting (Cloudflare Pages)

- Repo: connect GitHub `main` to Cloudflare Pages.
- Build command: leave empty, or `python3 scripts/build_site.py` if you regenerate on deploy.
- Output directory: `/` (site root).
- Live: https://vchsphotography-website.pages.dev

After content edits, regenerate portfolios before pushing:

```bash
python3 scripts/build_site.py
```

## Updating content (no redesign)

| What | File |
|------|------|
| Site name, nav, contact, Instagram, phone, form delivery | `data/site.json` |
| Photographers, specialties, galleries | `data/photographers.json` |
| Projects & status labels | `data/projects.json` |
| Equipment wishlist & estimates | `data/wishlist.json` |
| Public sponsor acknowledgments | `data/sponsors.json` |
| Impact metrics (hidden until publish) | `data/impact.json` |
| Folder → photographer credits | `data/gallery-credits.json` |

Gallery photos: drop JPGs into `assets/club/<slug>/web/` (and matching `full/` if used). **Name the folder with the photographer** (e.g. `allen-rally`, `week5-ethan`, `nova-katherine`). Then:

```bash
python3 scripts/build_site.py
python3 scripts/apply_credits.py
```

`apply_credits.py` writes captions from the folder map (and filename tokens like `allenwu` / `danielan` when the folder is mixed). Unknown folders stay **Credit pending** — do not invent names.

## Booking (photographer email)

`book.html` lets visitors pick a photographer. If that person has an `email` in `data/photographers.json`, submit opens the visitor’s mail app (`mailto:`) addressed **only to that photographer**, with the inquiry prefilled.

- Add emails only for members who **consent** to a public booking contact.
- Leave `email` blank to keep them listed as “(club DM)” — visitors get a clipboard draft for `@vchs_photography` naming that person.
- “Any available photographer” opens one email **To:** every photographer who has an `email` filled in (comma-separated). If none are set yet, it falls back to an Instagram DM draft.

The static site cannot send email by itself. `mailto:` opens the visitor’s email app. For server-side delivery later, set `formEndpoint` (Formspree, etc.) on the sponsor form in `donate.html`.

## Sponsor form (delivery)

Sponsor inquiries on `donate.html` still use `formEndpoint` or `inquiryEmail` from `data/site.json`, or clipboard → Instagram if neither is set.

## Impact metrics

`data/impact.json` stays hidden on the homepage until `"publish": true` **and** metrics have verified `value` strings. Do not invent counts.

## Sponsors

Add approved entries to `data/sponsors.json` → `entries[]` with `name`, optional `url`, optional `blurb`. Leave `seeking: true` while actively looking for partners.

## School / policy checklist before public launch

- [ ] Confirm donation wording with school administration
- [ ] Confirm booking / paid-service approval path
- [ ] Confirm Instagram handle and public phone
- [ ] Set `formEndpoint` or `inquiryEmail` and test a submission
- [ ] Obtain photo release / consent for published images of minors
- [ ] Do not publish student personal emails without consent
- [ ] Do not claim 501(c)(3) status or tax deductibility
- [ ] Do not show fixed prices until officers approve rates (site uses “Request a quote”)
- [ ] Do not publish fundraising totals until tracking is reliable
- [ ] Do not set `impact.json` publish until numbers are verified

## Custom domain (optional)

In Cloudflare Pages → Custom domains, add the school-approved hostname and follow DNS instructions. Update `og:` / canonical URLs in HTML if you want absolute social preview links.

## Favicon / branding

Replace `assets/favicon.svg` when the club has an approved logo. Theme color is PMS navy `#00467F`.

## Privacy

Booking and sponsor forms may collect name, email, organization, project details, and contribution interest. Use only to respond to inquiries. See `privacy.html`. Photo removal: contact the club Instagram in the site footer.
