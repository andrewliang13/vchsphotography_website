# VCHS Photography

The public portfolio site for the Valley Christian High School photography collective.

## Site

This is a static, single-page site built with HTML, CSS, vanilla JavaScript, GSAP, and temporary Unsplash photography. The stock images are clearly identified in the interface and can be replaced with student work directly in `index.html`.

## Local preview

Open `index.html` directly or serve this directory with any static web server.

## Hosting

The production site is deployed as a static Cloudflare Pages project.
